Tailwind CSS MVP

A minimal implementation of utility-first CSS generation

What is this?

This MVP demonstrates the core concept of Tailwind CSS: scanning HTML for utility classes and generating only the CSS that's actually used.

Centered with Flexbox utilities

Features

Color Utilities

Background, text, and border colors

Spacing

Padding and margin utilities

Layout

Flexbox and display utilities

How It Works

  1. 1. Scans your HTML for class names
  2. 2. Matches classes against utility patterns
  3. 3. Generates minimal CSS with only used utilities

Built as an MVP demonstration of Tailwind CSS concepts
